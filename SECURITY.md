# Security Policy

## Supported Versions

Only the latest release of Launcher receives security fixes from this
repository: https://github.com/Lakphy/launcher/releases

## Reporting a Vulnerability

Please use GitHub private vulnerability reporting:
https://github.com/Lakphy/launcher/security/advisories/new

Please don't open a public issue for anything you believe is
exploitable before it has been fixed. Include reproduction steps and
the Launcher version (Launcher → About Launcher) you tested.
